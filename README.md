# CudaQuest — 72 Hours of Innovation

CudaQuest is a premier 72-hour hackathon focused on AI/ML/MATLAB/IoT innovation and simulation excellence.

## Tech Stack
- **Framework:** Vite + React
- **Styling:** Tailwind CSS, Custom Cyber-Tech Neon Styling
- **Typography:** Funnel Display, Doto, Space Mono

## Getting Started Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

The site will be live at `http://localhost:3001`.
